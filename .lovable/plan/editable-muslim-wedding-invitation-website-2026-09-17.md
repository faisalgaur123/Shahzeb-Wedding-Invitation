# Editable Muslim Wedding Invitation Website

## Experience
- Replace the blank home screen with a polished invitation that opens from an animated ivory envelope.
- Build five navigable views: Welcome, Our Story, Events, Gallery, and RSVP.
- Keep the approved warm ivory, champagne, blush, taupe, and subtle-gold visual direction with editorial serif typography and restrained motion.
- Use the generated wedding artwork as visual guidance while keeping the live names, date, photo, and details as editable website content.

## Built-in editor
- Add an unobtrusive editor panel for bride name, groom name, wedding date, event details, venue, and couple photo.
- Support photo upload from the visitor’s device, live preview, reset to placeholders, and browser persistence so edits survive refreshes on that device.
- Validate text lengths, image type, and image size before applying changes.

## Invitation details
- Show the Arabic Bismillah, editable couple names, save-the-date display, live countdown, event schedule, map link, photo gallery, and RSVP form.
- Keep placeholder wording and imagery until replaced; do not invent private wedding details.
- RSVP will be a polished interactive preview stored only in the current browser; no remote guest database or email delivery is included.

## Technical details
- Implement the five-view experience at the home address with accessible tab-style navigation and smooth transitions.
- Store customization locally in the browser after hydration to avoid loading mismatches.
- Use semantic color and typography tokens in the global design system, responsive layouts, reduced-motion support, and route-specific metadata.
- Verify desktop and mobile presentation, editor interactions, photo replacement, countdown behavior, and RSVP confirmation.
