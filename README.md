# Dreamy Digital Blooms

Create a luxurious, modern, feminine Muslim wedding invitation website advertisement, inspired by the uploaded reference image. Use the reference only for layout inspiration, but create a fresh, beautiful, premium design.

FORMAT:

Vertical 9:16 Instagram Story / social media poster.

Ultra-high-resolution, elegant editorial product photography, premium wedding branding.

OVERALL AESTHETIC:

Modern luxury wedding stationery, dreamy animated aesthetic, soft romantic atmosphere, Pinterest-trending wedding design, feminine and elegant, minimal Scandinavian style, delicate floral details, warm cinematic lighting.

COLOR PALETTE:

Warm ivory, champagne beige, soft blush pink, cream, muted rose, taupe, and subtle gold accents. Soft creamy background with natural sunlight, realistic shadows, and a luxurious neutral atmosphere.

MAIN COMPOSITION:

Place two elegant modern smartphones side by side in the center of the poster, displaying a beautiful interactive wedding invitation website.

Surround the phones with:

- Delicate white flowers and baby’s breath

- Soft silk ribbons

- Pearl details

- Elegant wedding rings

- A small ceramic plate

- Translucent fabric

- Subtle flower petals

- Soft golden light reflections

Keep the composition clean, spacious, balanced, and premium.

LEFT SMARTPHONE — OPENING INVITATION:

Display an elegant digital wedding invitation envelope on the phone screen.

Design:

- Soft ivory envelope

- Delicate floral wax seal

- Minimal Arabic calligraphy

- Elegant cream background

- Subtle glowing animation effect

- Beautiful cursive text at the bottom:

“Tap to Open”

Make the envelope look like an interactive animated invitation that opens when tapped.

RIGHT SMARTPHONE — MAIN WEDDING HOMEPAGE:

Display a beautiful wedding invitation website homepage with the following editable placeholder content:

“[BRIDE NAME] & [GROOM NAME]”

“بِسْمِ اللَّهِ الرَّحْمَنِ الرَّحِيمِ”

“SAVE THE DATE”

“[DD] | [MM] | [YY]”

Below the date, display a romantic cinematic wedding photograph of the couple holding hands, softly blurred with warm golden lighting.

IMPORTANT:

The couple’s photo must be replaceable.

The bride’s name and groom’s name must be replaceable.

The wedding date must be replaceable.

Do not permanently lock the names, date, or photograph into the design.

Show them as editable placeholders suitable for a Canva wedding invitation website template.

TOP HEADLINE:

“WEDDING WEBSITE”

SUBTITLE:

“5 BEAUTIFUL PAGES”

SMALL BADGE:

“EDITABLE IN CANVA”

BOTTOM FEATURES:

Add three elegant minimal line icons with clean labels:

COUNTDOWN TIMER

BUILT-IN RSVP FORM

LOCATION

(GOOGLE MAPS)

Use delicate gold or taupe line icons, evenly spaced, with thin vertical separators.

ANIMATED AESTHETIC:

Make the design feel like a premium animated wedding invitation website brought to life:

- Floating flower petals

- Soft glowing highlights

- Gentle shimmer

- Delicate light leaks

- Subtle sparkle effects

- Elegant motion-inspired details

- Dreamy cinematic atmosphere

The design should look like a beautiful interactive digital wedding invitation, not a traditional printed card.

TYPOGRAPHY:

Use elegant high-fashion serif typography for headings, refined modern sans-serif for supporting text, delicate cursive script for “Tap to Open,” and graceful Arabic calligraphy.

Ensure all text is clean, correctly spelled, readable, professionally aligned, and beautifully balanced.

QUALITY:

Photorealistic premium product photography, realistic smartphone reflections, soft natural window light, warm champagne glow, elegant shadows, ultra-detailed, 4K quality.

IMPORTANT DESIGN RULES:

- Keep the layout inspired by the reference image.

- Make it more feminine, modern, animated, and visually captivating.

- No clutter.

- No harsh colors.

- No distorted smartphones.

- No extra text.

- No watermark.

- No logo.

- Make the wedding photo, names, and date clearly replaceable/editable placeholders.https://pin.it/pjtdVbtmj
